📦 Mock Media Server

This API allows you to upload, view, and download media files. Below are the available endpoints and how to use them.

🔗 API Endpoints

  • GET /
    Returns this HTML file. This is your API documentation page.
  • POST /upload
    Upload a media file using multipart/form-data.
    Required field: file
    Optional field: title
    Example: Use Postman or an HTML form with file upload support.
  • GET /media
    Returns a JSON array of all uploaded media metadata. Each item contains:
    • title: Title of the media
    • filename: The stored filename
    • uploadedAt: Date/time it was uploaded
  • GET /download/:filename
    Downloads the specified media file.
    Example: /download/image1.jpg

Example Media Metadata Format

[
  {
    "title": "Sunset Photo",
    "filename": "sunset.jpg",
    "uploadedAt": "2025-04-29T18:20:33.411Z"
  }
]
